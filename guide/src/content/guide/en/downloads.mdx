## Colour and type tokens

| File | Contents |
| --- | --- |
| [ais-theme.css](/downloads/ais-theme.css) | The Tailwind v4 theme: `@aisgroup/design/styles.css`, the Rosepetal products' tokens |
| [ais-tokens.css](/downloads/ais-tokens.css) | The same values as CSS custom properties, for print, email and anything without Tailwind |
| [ais-tokens.json](/downloads/ais-tokens.json) | Design tokens (W3C DTCG format) |
| [ais-web-theme.css](/downloads/ais-web-theme.css) | Tailwind’s text sizes as the brand type styles, and the field border, on ais-theme.css and ais-tokens.css. The websites use its type block on ais-tokens.css alone; see [Website components](/en/web-components/#set-up). |

Every product is built with Tailwind v4 on ais-theme.css, the Rosepetal products’ tokens (`@aisgroup/design/styles.css`), so the classes are the app’s: `bg-primary`, `text-muted-foreground`, `bg-page`, `border-border`. It needs `tw-animate-css`. The websites load ais-tokens.css instead, under their own components; see [Website components](/en/web-components/#set-up).

```css
@import "tailwindcss";
@import "./ais-theme.css";
```
