## Tokens de color i tipografia

| Fitxer | Contingut |
| --- | --- |
| [ais-theme.css](/downloads/ais-theme.css) | El tema de Tailwind v4: `@aisgroup/design/styles.css`, els tokens dels productes de Rosepetal |
| [ais-tokens.css](/downloads/ais-tokens.css) | Els mateixos valors com a variables CSS, per a impressió, email i tot el que no faci servir Tailwind |
| [ais-tokens.json](/downloads/ais-tokens.json) | Tokens de disseny (format W3C DTCG) |
| [ais-web-theme.css](/downloads/ais-web-theme.css) | Les mides de text de Tailwind com a estils tipogràfics de la marca, i la vora de camp, sobre ais-theme.css i ais-tokens.css. Els webs fan servir el seu bloc tipogràfic només sobre ais-tokens.css; vegeu [Components dels llocs web](/ca/web-components/). |

Cada producte es construeix amb Tailwind v4 sobre ais-theme.css, els tokens dels productes de Rosepetal (`@aisgroup/design/styles.css`), així que les classes són les de l’app: `bg-primary`, `text-muted-foreground`, `bg-page`, `border-border`. Necessita `tw-animate-css`. Els webs carreguen ais-tokens.css en el seu lloc, sota els seus propis components; vegeu [Components dels llocs web](/ca/web-components/).

```css
@import "tailwindcss";
@import "./ais-theme.css";
```
