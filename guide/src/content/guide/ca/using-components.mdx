Instal·la el paquet de producte i fes servir els seus components i tokens conjuntament.

## Preparar una aplicació

1. Configura el registre privat i instal·la `@aisgroup/design`, com explica el README del paquet.
2. Importa `@aisgroup/design/styles.css` després del tema i les utilitats de Tailwind.
3. Importa els components per carpeta i els blocs per fitxer: `import { Button } from '@aisgroup/design/ui/button'`, `import TopBar from '@aisgroup/design/blocks/TopBar.vue'`.
4. Fes servir un bloc allà on encaixi: TopBar per a la barra, PageLayout per a cada pàgina (amb el seu menú lateral si la pàgina en té), LoginPage i ConfirmDialog. Parteix dels seus exemples.
5. Quan les notes de disseny pròpies de l’aplicació no coincideixen amb el paquet o amb aquesta guia, mana el paquet: canvia les notes.
6. Mantén Inter i la pàgina a tota l’amplada, i obre cada pàgina sota el bloc TopBar.
7. Afegeix un test que falli amb punts volats o fletxes Unicode a les plantilles, com `tests/uiTextRules.spec.js` de rosepetal-ui.

## Compondre, no reestilitzar

Les classes d’un component només el col·loquen a la pàgina. El seu aspecte ve de la seva variant i la seva mida.

```vue
<div class="flex items-center justify-between gap-6">
  <div class="flex flex-col gap-1">
    <h2 class="font-heading text-lg font-medium">Models</h2>
    <p class="text-muted-foreground">3 models</p>
  </div>
  <Button><PlusIcon data-icon="inline-start" />Model nou</Button>
</div>
```

## Botons

| Variant | Per a |
| --- | --- |
| `default` | L’acció principal d’una pàgina, secció o diàleg |
| `outline` | Accions secundàries i barres d’eines |
| `ghost` | Accions d’icona i de fila |
| `secondary` | Cancel·la, al peu d’un diàleg |
| `destructive` | Esborrats, després d’una confirmació que anomena el que s’esborra |
| `link` | Accions de text dins d’una frase |

Els botons de capçalera i de barra d’eines són `h-9` (36 px); les icones, de 16 px. A les pantalles tàctils i als panells d’operari, les zones interactives fan 44 px. `topbar` i `topbar-tab` són només per a la barra superior i `modal` només per al peu dels diàlegs.

## Quin component per a cada cas

| Contingut | Fes servir |
| --- | --- |
| Llistes de files | Files separades per línies (`divide-y border-y`), la fila triada `bg-muted font-medium` |
| Taules | Table amb capçaleres ordenables i Pagination numerada; les columnes de nombres porten `text-right tabular-nums` a TableHead i TableCell |
| Datasets, models, imatges | Item `variant="outline"`; les fitxes d’imatge `size="sm"` amb la imatge com a ItemHeader |
| Dades | Una graella d’etiqueta sobre valor (`dt` atenuat, `dd`) |
| Formularis | Field, FieldGroup i FieldDescription, etiqueta sobre el control, `max-w-sm` |
| Un de pocs modes | RadioGroup de targetes d’opció; triar eina és un ToggleGroup |
| Triar d’una llista llarga | Combobox amb cerca; una llista curta és un Select |
| Accions de fila | Un botó ghost `icon-sm` amb Ellipsis que obre un DropdownMenu |
| Seccions una al costat de l’altra | Cards en `grid gap-4 xl:grid-cols-2`; les Cards d’una fila comparteixen la seva alçada, així que sense `items-start` |
| El compte | Un Avatar a la barra superior que obre un DropdownMenu; el seu últim element és Log out |
| Estat | Una icona amb el seu to i la paraula, en text atenuat |
| Càrrega | Skeleton amb la forma del contingut; Spinner dins del botó que treballa |

## Diàlegs

DialogHeader (el títol sobre una banda grisa), DialogBody i DialogFooter amb botons a tota l’amplada: Cancel·la `variant="secondary" size="modal"` primer i l’acció `size="modal"` després. Als diàlegs amb formulari, el formulari porta un `id` i el seu botó d’enviament va al peu. Els botons del peu porten només text (Crea, Desa); mentre l’acció treballa, un Spinner va dins del seu botó. Un clic a fora o Esc tanca el diàleg, excepte mentre la seva acció treballa.

## Notificacions i confirmacions

Les notificacions són `toast()` de `vue-sonner`, que es crida des de qualsevol lloc, amb un sol Toaster a App. Una confirmació és el bloc ConfirmDialog; el codi que pregunta sense una pàgina pròpia, com una opció de menú o un store, crida `useConfirm().ask()`, i la mostra l’únic ConfirmHost d’App.

## Colors de dades

Etiquetes, sèries de gràfics i particions de dataset tenen colors propis a `@aisgroup/design/styles.css`: les etiquetes (`--tag-normal`, `--tag-anomaly`, `--tag-default`, `--tag-unclassified`), les particions (`--split-train`, `--split-validation`, `--split-test`, `--split-predetermined`) i les sèries de gràfics (de `--chart-1` a `--chart-3`):

- Els colors d’etiqueta són iguals en mode clar i fosc, de manera que una classe de defecte mai no canvia de color; la primera i la tercera sèrie i la partició d’entrenament passen a un to més clar en mode fosc. Tots els tokens en els dos modes són a [Temes clar i fosc](/ca/themes/#tokens).
- Mai no apareixen a la navegació, als botons ni als gràfics de màrqueting.
- Cadascun va amb la seva etiqueta; el color sol mai no identifica una classe.

## Maquetació i zones interactives

Les pantalles de producte ocupen tota l’amplada. Fan servir els punts de ruptura de Tailwind, no la retícula dels webs. A l’escriptori, els botons de barra d’eines i de capçalera fan 36 px (`h-9`), amb icones de 16 px; a les pantalles tàctils i als panells d’operari, cada zona interactiva fa 44 px. El text segueix l’escala de producte de [Tipografia](/ca/typography/).

Els menús, els botons, les pestanyes i els Badge s’ajusten a la seva etiqueta més llarga: mai passen a una altra línia ni es tallen. Les dades llargues de l’usuari es trunquen, amb el text complet en un Tooltip o a `title`. Els botons d’una mateixa fila tenen la mateixa alçada.
