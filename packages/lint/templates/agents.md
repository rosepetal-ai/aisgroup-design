## UI

Screens use `@aisgroup/design` and the AIS Group product UI rules. With the AIS Group Design plugin, build or change a view with its `product-ui` skill and redesign a whole app with `ui-unify`. Before you finish a UI change, run `__RUN__ lint:ui`; for a changed screen, also `__RUN__ check:ui`. A finding names its fix; if one is a false positive, say so instead of working around the rule.
