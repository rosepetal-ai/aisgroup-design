# Writing essentials

Apply these rules to the reply as well as the artifact. Before returning, check every prose quotation, including quoted UI labels, source-section names and proposed placeholder wording. Use «» there; preserve code syntax and literal JSON or file values. A source citation does not turn an explanatory prose quotation into code.

## AIS-9a4a6d01fd41

<!-- AIS-9a4a6d01fd41 -->
«» quotes in EVERY language, English included; “ ” only inside them.

Source: brand decisions.

## AIS-1c8a044b9233

<!-- AIS-1c8a044b9233 -->
Never «·» as a separator anywhere (labels, pieces, notes, signatures, UI). Only Catalan l·l inside a word. Use structure instead, never «|», «—» or «/» as a stand-in.

Source: brand decisions.

## AIS-b5386523c3f8
