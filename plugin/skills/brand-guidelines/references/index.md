# Brand design

## Principles

- **Precise.** Exact values, legible data and the same components everywhere. If it can be measured, show the measurement.
- **Proven.** Real machines, real installations and real screens are the evidence. Claims carry their conditions.
- **Clear.** Direct words and one obvious reading order. An operations team should understand it on first read.

## The essentials

1. **Keep it simple:** one purpose, the plainest layout, design and implementation that serve it. Linear’s website and Apple Notes are the bar. Cut taglines, helper text, subtitles, eyebrows and secondary labels; if something only makes sense with them, fix the layout instead. A decision ships only if it improves user, developer and agent experience at once. When two rules disagree, this one wins.
2. Write the names exactly: **AIS Group**, **AIS Vision Systems**, **AIS Vision Automation**, **AIS Scanology**, **Rosepetal** (one word, capital R only). Never translate them.
3. The brand colour is **blue `#17356E`**. One-colour jobs use this blue; black only where the production can print nothing else.
4. Use only the supplied logo files: blue on light backgrounds, white on blue or dark, black only for black-only printing and AIS website headers on white. Never redraw, recolour, stretch or regenerate a logo.
5. Set everything in **Inter** (Regular 400, Medium 500, Semibold 600) with the text styles on the Typography page; code and machine values in **JetBrains Mono**. Fall back to Arial only when Inter cannot be installed.
6. Use **sentence case** for every headline, title, button and label, in every language.
7. **Eight core colours** carry the brand. Every other colour is a step of their scales (blue 50–950, neutral 0–900) or a status colour; charts add the data colours. Never use a colour outside the palette or a nearby value.
8. **Show proof, not claims:** real machines, real screens, measured results with their conditions. No superlatives or invented figures.
9. Draw icons and arrows with **Lucide**, the library the Rosepetal design system uses: used as shipped (2 px stroke on its 24 px grid). Never type Unicode arrows, ticks or emoji (`→`, `✓`, `•`) as icons.
10. **Localise, do not translate:** write English, Spanish and Catalan natively, with each language’s own conventions.
