# Vuetify

Source and complete component mapping: packages/vue-themes/README.md, generated themes: packages/vue-themes/vuetify.mjs. Use design_code kind=vuetify for download and mapping URLs. Configure createVuetify with the exported theme options and switch between aisLight and aisDark. Read product-ui/references/using-components.md for behaviour. Colours are adapted; geometry, density, typography and icons still need an app adapter and actual visual checks.
