# Product screenshots for marketing

Use an approved screenshot if its product version, screen state and resolution suit the piece. Capture the actual interface when the brief asks for a fresh image or the existing one cannot show the reader what matters.

## Get to the screen

Reuse the app URL or authorized browser tab supplied for the task. If the location or example is missing, ask only for what you need, such as «Which app URL should I open?» or «Which product state should the reader see?» Ask for the ordinary app address without sign-in tokens.

If the app requires authentication, ask the user to sign in directly to that app in the shared browser, including SSO or MFA. For assisted sign-in, use the host’s secure credential prompt for the intended origin. Keep credentials, one-time codes and session tokens out of chat, commands, logs, screenshots and project files. Resume once the user reaches the requested screen. If private sign-in or browser capture is unavailable, ask for a screenshot of that state and continue the rest of the piece.

Use an authorized demo or fixture if reaching the screen would change a live system. Identify demo values as examples. In private source notes, record the screen and build when known and the source of any measurement used in the copy. A nominal catalogue dimension and a reading from the machine support different claims.

## Frame the evidence

Show the workspace when the reader needs to see how its parts relate. For a single setting, capture the whole dialog or panel at native resolution with its title, units, value and relevant action visible. For a rounded dialog shown on its own, isolate its outline on transparency or the actual page colour. Preserve the displayed values.

Place the image once and caption what the reader should understand or decide. Inspect the exported page at reading size for legibility, cut-off controls, background showing at the corners and unintended account or customer details. Keep customer-specific captures with the authorized piece unless separately approved for library use.
