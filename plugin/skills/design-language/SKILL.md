# design-language

Apply the [writing essentials: use «» for prose quotes, UI labels and section names in every language; no decorative separators or English contractions](../communications/references/writing-essentials.md) to this reply and artifact; preserve syntax in code, JSON and raw file excerpts. [Production rules](../_shared/references/production-rules.md): no glow or gradients; mascots and illustrations stay held; no public CAD or mesh downloads.

Rule [AIS-cba1a88e1cbf: Keep it simple: one purpose, the plainest layout, design and implementation that serve it.](../brand-guidelines/references/retained-rules-01.md#ais-cba1a88e1cbf).

1. Identify the medium: product UI, web or communications. Their type, grid and corner rules differ.
2. Load only the relevant topic below. Read themes.md for light/dark behaviour and tokens.md for exact values.
3. Apply the guide’s existing rules. Do not create new brand standards to fill a missing example.

For control geometry, compare [product controls](../product-ui/references/using-components.md) with [website controls](../web-design/references/web.md); for reports use digital-documents. Website fields have their own [48 px rule](../web-design/references/retained-rules-01.md#ais-dc34a55153e4); absence from product tokens does not establish absence from the web contract.
