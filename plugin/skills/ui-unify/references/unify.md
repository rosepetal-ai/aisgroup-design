# Unify an existing product UI

Use product-ui/references/using-components.md and registry/package code as the target. For a whole app on PrimeVue, Vuetify or its own styles, follow [redesign](redesign.md). Audit and inventory the current screen first. Preserve behaviour, image/dataset cards, content and state transitions while replacing one component family. Run the actual application build and tests, inspect both modes and test keyboard/async states. No automatic codemod or browser audit exists here; do not claim these checks ran without evidence.
