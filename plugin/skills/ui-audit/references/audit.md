# Product UI audit

Source rules: product-ui/references/using-components.md; design-language/references/accessibility.md and themes.md. Run scripts/ui-contract.mjs audit on changed Vue/CSS source. Its findings cover literal colours, stock palette classes, radius overrides, separators and Unicode arrows; comments and data strings can produce candidates requiring inspection. It cannot prove contrast, keyboard operation or target size. Inspect the actual component source and runtime before declaring a violation. Report file and line, source rule, evidence and fix; separate unverified runtime checks.
