# Product UI audit

Source rules: product-ui/references/using-components.md; design-language/references/accessibility.md and themes.md. Run scripts/ui-contract.mjs audit on changed Vue/CSS source. Its findings cover literal colours, stock palette classes, radius overrides and raw radii in CSS, separators and Unicode arrows, icons in dialog footer buttons, dialogs that never close on a click outside, Sign out in the account menu, and, as checks, small text and side-by-side grids with items-start; comments and data strings can produce candidates requiring inspection. It cannot prove contrast, keyboard operation or target size. Inspect the actual component source and runtime before declaring a violation. Report file and line, source rule, evidence and fix; separate unverified runtime checks.
