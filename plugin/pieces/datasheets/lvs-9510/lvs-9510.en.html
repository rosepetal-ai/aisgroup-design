Omron LVS-9510

Desktop barcode verification system. The LVS-9510 verifies barcodes off-line to ISO/IEC, ANSI, GS1 and UDI standards. It verifies linear (1D) and two-dimensional (2D) codes without changing equipment.

ISO/IEC, ANSI, GS1 and UDI standards

1D and 2D codes

Automatic symbology and aperture

Comes with a handheld top cover, not shown, to keep the label in position on the viewing window.

Verification

The «stitching» feature allows grading of barcodes larger than the field of view.

Inspects all nine ISO/ANSI parameters for 1D barcodes, identifies blemishes and allows simple human-readable validation. For 2D codes, reports all parameters specified by the applicable symbology specification.

It automatically determines the symbology and aperture needed to evaluate the code and identifies and highlights trouble spots. Analytical tools identify and evaluate errors, with problems highlighted using colour coding.

Certified by GS1 US. 21 CFR Part 11 compliant-ready.

Supports 15 languages, with the ability to add more. Quality data reporting for auditing purposes.

Includes a NIST-traceable calibrated conformance standard test card for calibrating the system.

Software and options

LVS-95XX software includes GS1 System Symbol Specification Tables. They set standards for barcode data structure and how to maintain code quality during creation. Omron Microscan offers online training on GS1 tables and their application to different organisations.

Permissions through LVS-95XX

Passwords are stored encrypted in a local database, include an expiration date and count failed attempts.

Permissions through Microsoft Active Directory

User privileges are based on Microsoft authentication and LVS-95XX permissions are assigned by group membership.

Multi-Sector

Software upgrade for verification of multiple barcodes on a label.

Enhanced Application Identifier Verification (EAIV)

Checks that GS1 application identifiers, such as expiration date, GTIN and batch number, embedded in a GS1 barcode data structure match the data programmed in EAIV by the user.

GS1 US certification
