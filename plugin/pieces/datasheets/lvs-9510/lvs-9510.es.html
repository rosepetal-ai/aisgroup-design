Omron LVS-9510

Sistema de verificación de códigos de barras de escritorio. El LVS-9510 verifica fuera de línea códigos de barras conforme a los estándares ISO/IEC, ANSI, GS1 y UDI. Verifica códigos lineales (1D) y bidimensionales (2D) sin cambiar de equipo.

Estándares ISO/IEC, ANSI, GS1 y UDI

Códigos 1D y 2D

Simbología y apertura automáticas

Se entrega con una cubierta superior portátil, que no aparece en la imagen, para mantener la etiqueta en posición sobre la ventana de visualización.

Verificación

La función de «combinación de áreas» permite evaluar códigos de barras de dimensiones mayores que el campo de visión.

Inspecciona los nueve parámetros ISO/ANSI de códigos 1D, identifica imperfecciones y permite validaciones sencillas de lectura humana directa. En 2D, informa de todos los parámetros de la especificación de simbología correspondiente.

Determina automáticamente la simbología y la apertura necesarias para evaluar el código e identifica y resalta los puntos conflictivos. Herramientas analíticas para identificar y evaluar errores, con problemas resaltados mediante códigos de color.

Certificado por GS1 US. Listo para cumplir con el 21 CFR Part 11.

Disponible en 15 idiomas, con posibilidad de añadir más. Informes de calidad de datos con fines de auditoría.

Incluye una tarjeta de prueba estándar de conformidad de calibrado trazable NIST para calibrar el sistema.

Software y opciones

El software LVS-95XX incluye las tablas de especificación de símbolos del sistema GS1. Establecen los estándares de estructura de datos y cómo mantener la calidad de los códigos durante su creación. Omron Microscan ofrece formación en línea sobre las tablas GS1 y su aplicación a distintas organizaciones.

Permisos mediante LVS-95XX

Las contraseñas se almacenan cifradas en una base de datos local, incluyen fecha de caducidad y registran los intentos fallidos.

Permisos mediante Microsoft Active Directory

Los privilegios se basan en la autenticación de Microsoft y los permisos de LVS-95XX se asignan según la pertenencia al grupo.

Multisector

Actualización de software para verificar múltiples códigos de barras en una etiqueta.

Verificación de Aplicación Mejorada (EAIV)

Comprueba que los identificadores de aplicación GS1, como fecha de caducidad, GTIN y número de serie, integrados en la estructura de datos de un código GS1, coincidan con los datos programados por el usuario en EAIV.
